# План и «долгий ящик»

## Ближайшее

- Живая проверка постпродакшна (`render_viewport`) с Rhino и обновления
  хоста через `.yak` с сервера.
- Панель инструментов Rhino (`.rui` в пакете) с кнопкой Stultus.
- Grasshopper: снимок открытого канваса в `get_scene` (компоненты, связи)
  и инструменты для канваса по образцу RhinoAI (McNeel): добавить компонент,
  соединить, задать слайдер, выполнить Python-компонент.

## Долгий ящик

- **Рендер штатным рендерером Rhino** (`_Render`, Cycles/Rhino Render) как
  инструмент с сохранением на диск — аналог `render_vray` у Stultus.
- **Общая память бюро**: заметки о проектах, договорённости по слоям и
  материалам; инструмент «вспомнить», пополнение фразой «запомни». На
  gateway, без веса в плагине.
- Автоматическая резервная копия документа перед первым изменением хода.
- Инструменты `set_material` / `set_layer` вместо кода.
- Лимит времени на Python: только если появится безопасный способ прервать
  CPython в RhinoCode.
- Rhino для Mac: Eto WebView там через `webkit.messageHandlers` — мост в
  окне надо научить обоим каналам.
- **Пульт главного архитектора**: страница на gateway с плиткой на каждое
  подключённое окно (как в ROADMAP Stultus).
